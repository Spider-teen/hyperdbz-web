Launcher / multi-ZIP import / compact archives:
https://github.com/Spider-teen/hyperdbz-web

Hosted audio: mono 16 kHz / 8-bit PCM WAV samples, 64 kbps MP3 music.
Character scripts and sprite files are preserved. Original ZIP imports use
the user's unmodified files and original audio. Imported files stay in the
browser and are remembered locally when storage permits. No browser netplay.

Experimental build. A playable match has not yet been verified; the remote
test browser has WebGL 2 disabled. Requires WebGL 2 and WebAssembly.
